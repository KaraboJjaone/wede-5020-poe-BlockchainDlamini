# CSS README

This folder contains the main stylesheet for the South African Business Council NPC website.

## Part 2 Styling Updates

For Part 2, the website styling was updated to use one shared CSS file:

All main HTML pages are linked to this stylesheet:

- `Index.html`
- `about.html`
- `services.html`
- `programmes.html`
- `enquiry.html`
- `contact.html`

## What styles.css includes

- Navigation bar styling
- Logo alignment
- Page layout styling
- Hero sections
- Cards and content sections
- Contact and enquiry forms
- Buttons
- Tables
- Footer styling
- Hover, focus, and active states
- Responsive design for smaller screens
